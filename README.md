# dnd-kit skills

給 AI coding agent 用的 [dnd-kit](https://dndkit.com) skills，內容對應 dnd-kit v0.5（2026-06）。

| Skill | 用途 |
| --- | --- |
| `dnd-kit-react` | React + TypeScript（`@dnd-kit/react`） |
| `dnd-kit-typescript` | 原生 TypeScript / JavaScript（`@dnd-kit/dom`） |

## 安裝

```bash
npx skills add <你的帳號>/<repo名稱>                       # 全部安裝
npx skills add <你的帳號>/<repo名稱> --skill dnd-kit-react  # 只裝其中一個
npx skills add <你的帳號>/<repo名稱> -g                     # 裝到使用者層級
```
